Dubnator v0.4.0 adds direct Engine DJ library and stems support, makes large
music collections responsive, and strengthens long-running performance use.

## Highlights

- Browse Engine DJ drives locally with their playlist hierarchy, track order,
  metadata and artwork intact.
- Load and control four synchronized Engine DJ stems: Vocals, Melody, Bass and
  Drums, including WebAssembly decoding where native Web Audio cannot decode
  the 8-channel AAC source.
- Restore deck playlists from IndexedDB and generate waveform envelopes in a
  worker so reloads and large collections stay responsive.
- Sort and filter the playlist library without changing load order. Aggregate
  folders are paginated and collapse independently, preventing large
  `ByArtistsss` collections from freezing the app.
- Open Engine drives through the modern directory picker and jump directly to
  `Engine Library` instead of enumerating unrelated files on the whole disk.
- Improved Launchpad feedback, deck activity LEDs, expanded deck views and
  high-frequency UI telemetry performance.
- Audio-device failures now preserve the browser's real error instead of
  reporting every failure as a blocked permission.

## Downloads

- **Windows:** MSI or setup EXE
- **Linux:** AppImage, DEB or RPM
